## 5. প্রতিটি phase-এ আসলে কী বদলাবে

**Phase 0 — baseline**
- `git tag pre-single-truth-2026-11-20`
- `tests/local-tool-cap.test.js`, `provider-env-lock-check.js`, `system-readiness-check.js` চালিয়ে output সংরক্ষণ
- `data/models.db` → `tmp/baseline/models.db` (VACUUM INTO)
- **কোনো code বদল নয়**

**Phase 2 — OpenCode**
- `.env` থেকে dead `OPENCODE_API_KEY` সরানো; `OPENCODE_ENABLED=false` রাখা
- `.env.example`-এ “paid only” নোট
- `provider/opencode.js` অপরিবর্তিত; capability row থাকবে

**Phase 3 — config**
- `lib/env.js` একমাত্র loader; `api.js`/`start.js`/`lib/expand-env.js` থেকে duplicate loader বাদ
- `catch (_) {}` → `CONFIG_FATAL key=... reason=...`; exit `78`
- নতুন size keys: `SESSION_MAX_BYTES`, `WEB_UI_MAX_BYTES`, `PROMPT_MAX_BYTES`, `TOOL_RESULT_MAX_BYTES`; 기존 `MAX_BODY_SIZE`, `MAX_FRAME_BYTES`, `MAX_HISTORY` একই table-এ

**Phase 4 — path + OS**
- `APP_ROOT`, `DATA_DIR`, `LOG_DIR`, `DB_SQLITE_PATH` — absolute required
- `resolveRuntimePaths()` + boot-এ `PATH_RESOLVED`
- `deploy/install.sh`: OS detect (Linux/macOS/Windows), package manager, systemd/launchd/Windows service; `APP_ROOT` স্ক্রিপ্টের নিজের directory থেকে
- `Caddyfile` template থেকে edge config; DNS নয়

**Phase 5 — tool budget**
- `lib/tool-budget.js` একটাই resolver
- `MCP_TOOL_BUDGET_MAX=24`, `MCP_TOOL_BUDGET_PIN`, `MCP_TOOL_BUDGET_MAX_BYTES`, `MCP_TOOL_BUDGET_MAX_PREFILL_MS`
- `limit = min(global, providerMax)`; pinned tool থাকবেই
- `MAX_TOOLS_LIMIT`, `Math.min(25, …)`, `maxTools: 15`, `|| 5` — সব বাদ
- `provider/tools.js`-এ `prepare()` cap enforce করবে

**Phase 6 — DB**
- `DB_SQLITE_PATH` required; missing → `DB_FATAL missing`; corrupt → `DB_FATAL corrupt`; exit `78`
- remote download বাদ; `MODELS_DB=null` degradation বাদ
- capability query error → `CAPABILITY_UNKNOWN` + deny (fail-closed)

**Phase 7 — provider pipeline**
- `normalizeResponse()` → OpenAI-compatible contract (100%)
- `adapters/openai.js`, `adapters/anthropic.js`, `adapters/vscode.js` — শুধু shape
- fallback ladder: primary → fallback → R2T tool parser (explicit log) → direct error
- health: success-এ `last_error=NULL`; probe ছাড়া auto-healthy নয়
- `request_log`: attempt, fallback_from, timeout_ms, tool_count, tokens

**Phase 8 — loopback + MCP**
- `DEFAULT_PROBE_PORTS` delete; `BRIDGE_PROBE_DEFAULTS=0`
- `BRIDGE_UPSTREAMS` explicit; self-reference fatal
- `isLoopbackHost()` এক জায়গায় (`localhost`, `127.0.0.1`, `::1`, `[::1]`)
- এক aggregator; duplicate MCP tool dedupe

**Phase 9 — quality**
- 30 cases: tool selection, groundedness, hallucination, injection, fallback, cost/latency
- Gate: pass ≥ 90%, injection escape 0, p95 < timeout, cost regression < 10%
- adapter golden tests: একই normalized object → তিন adapter

**Phase 10 — release**
- `dist/` build provenance (git SHA + sha256)
- service `ExecStart` root `start.js` (dist নয়)
- logs/artifacts retention
- runbook + syllabus update
