## ০. এই ডকুমেন্টের নীতি

এই ডকুমেন্ট কোনও প্রস্তাবনা নয়। এটি একটি **এক্সিকিউশন স্পেসিফিকেশন**। যে কেউ, যে কোনও সময়, এই ফাইলটি পড়ে ধাপগুলো চালাতে পারবে — আমার উপস্থিতি লাগবে না।

পাঁচটি নীতি, অলঙ্ঘনীয়:

1. **নতুন কিছু বানানো হবে না।** যা আছে তার সাথে যা আছে জোড়া দেওয়া হবে। প্রতিটি ধাপে লেখা আছে কোন ফাইল, কোন লাইন, কোন ফাংশন ইতিমধ্যে কাজটা করে — এবং কী যোগ করলে সেটা সম্পূর্ণ হয়। নতুন মডিউল তখনই, যখন টেবিলে "নেই" লেখা থাকবে।
2. **সময়ের অনুমান লেখা হবে না।** "পাঁচ দিন", "দুই সপ্তাহ" — এসব পরিকল্পনা নয়, প্রতিশ্রুতি, আর প্রতিশ্রুতি ভাঙা মিথ্যা। কোড লেখা সেকেন্ডের কাজ; যা সময় নেয় তা হলো যাচাই। তাই প্রতিটি ধাপের শেষে **যাচাই কমান্ড ও প্রত্যাশিত আউটপুট** আছে, সময় নয়।
3. **ভুল স্বীকৃত, মিথ্যা নয়।** কোনো ধাপ চালিয়ে প্রত্যাশিত আউটপুট না মিললে ডকুমেন্টে সেটি ব্যর্থ হিসেবে লিখে চালিয়ে যেতে হবে, ব্যাখ্যা বানিয়ে "সফল" বলা যাবে না।
4. **এক সত্য।** একই কাজের দুইটা implementation থাকবে না, দুইটা রেসপন্স ফরম্যাট থাকবে না, দুইটা ট্রান্সপোর্ট-নীতি থাকবে না। দ্বিতীয়টা পাওয়া গেলে প্রথমটা মুছে যাবে, পাশে রাখা যাবে না।
5. **কোডে বাংলা নেই, ইমোজি নেই, লুকানো ওয়াটারমার্ক নেই, অপ্রত্যাশিত কমেন্ট নেই।** কমেন্ট লেখা হবে শুধু "কেন" বোঝাতে, "কী" নয় — কোড নিজেই "কী" বলে।

### লগ থেকেই যা বেরিয়ে এলো

**ক. কনটেক্সট বড় — প্রমাণ টোকেনে:**

```
[WARN] [PROVIDER_FALLBACK] {"provider":"groq","error":"Request too large for model
`openai/gpt-oss-120b` ... tokens per minute (TPM): Limit 8000, Requested 32862"}
```

একটি অনুরোধ ৩২,৮৬২ টোকেন চেয়েছে, যেখানে ফ্রি টিয়ারের সীমা ৮,০০০। অর্থাৎ প্রম্পট প্রায় ৪ গুণ বড়। এটাই "ফ্রি মডেলের জন্য কনটেক্সট ভুল" — অনুমান নয়, সার্ভারের নিজের লগ।

**খ. অ্যাডমিন UI নিজের সার্ভারকেই ব্লক করছে:**

```
[WARN] [MCP_GATE_DENIED] {"tool":"write_file","origin":"http://127.0.0.1:5050","remote":"127.0.0.1"}
```

`Origin: http://127.0.0.1:5050` — সার্ভার নিজেই যে পেজ সার্ভ করে, সেই পেজ। কিন্তু allowlist-এ কেবল `APP_URL` (পাবলিক https নাম) ছিল, তাই `write_file`/`delete_file` আটকে যাচ্ছিল। **এই ডকুমেন্ট লেখার সময়ই ঠিক করা হয়েছে** (§৯.১)।

**গ. ক্লায়েন্ট হেডার রিজেক্ট — কিন্তু কারণ লগে নেই:**

```
[WARN] [MCP_HEADER_REJECTED] {"client":"unknown","errors":["ZC_MCP_VERSION"]}
```

১৫ বার। কোন ভ্যালু পাঠানো হয়েছিল তা লগে লেখা ছিল না, তাই ডিবাগ অসম্ভব ছিল। **লগে `detail` যোগ করা হয়েছে** (§৯.২)।

**ঘ. ডকুমেন্ট নিজেই পুরোনো:** `api.js`-এর ভেতরের TOC ৫,৯৩২–৭,৩৬১ লাইন পিছিয়ে (`AUDIT §২`)। যে ডকুমেন্ট ভুল লাইন দেখায়, সেটি ডকুমেন্ট নয় — বিভ্রান্তি।

## ৪. ধাপ ১ — `mcp` প্যারামিটার: প্রতি-রিকোয়েস্ট টুল পলিসি

**আছে:** `lib/tool-budget.js` ইতিমধ্যে ক্যাটালগ ২৪-এ কাটে, পিন করা টুল আগে রাখে, ইনটেন্ট স্কোর দিয়ে বাছাই করে, বাইট ও প্রিফিল-সময়ের বাজেট মানে। `api.js:4928 mcpGate` প্রিভিলেজড টুলে টোকেন চায়।

**গ্যাপ:** এই বাজেট **মডেল-পাথে** প্রয়োগ হয়, কিন্তু `tools/list` (MCP ক্লায়েন্ট, `GET /mcp`) পুরো ১০১টা টুল ফেরত দেয়। ফলে ওপেনকোড/IDE ১০১টা টুলের ক্যাটালগ বহন করে — যেটা §১-এর ৩২,৮৬২ টোকেনের অংশ। আর ক্লায়েন্ট নিজে বলতে পারে না "এই টার্নে আমার শুধু এই তিনটা টুল"।

**করণীয় (ক):** `/api/input`, `/v1/chat/completions`, `/mcp` — তিন জায়গায় `mcp` ফিল্ড পড়তে হবে, একই ফাংশন দিয়ে:

```json
{
  "mcp": {
    "servers": ["notes"],
    "tools": ["note_get", "note_set"],
    "budgetChars": 4000
  }
}
```

নিয়ম (deny-by-default):
- `mcp` অনুপস্থিত → শুধু রিড-অনলি টুল।
- `mcp.tools` দেওয়া → ঠিক সেগুলো + রিড-অনলি; অজানা নাম `unknown[]`-এ ফেরত।
- `mcp.budgetChars` → `toolBudget`-এর `maxBytes`-এ ক্ল্যাম্প, বাড়াতে পারবে না।
- প্রিভিলেজড টুল (`terminal`, `write_file`, …) `mcp.tools`-এ থাকলেও `mcpGate` টোকেন ছাড়া ছাড়বে না — পলিসি কখনো auth-এর বিকল্প নয়।

**করণীয় (খ):** `tools/list`-এও একই রেজলভার — `toolBudget.resolveToolBudget()`-কে `limit` পাস করে ডাকতে হবে, `Object.keys(MCP_TOOLS)` নয়।

**যাচাই:**
```bash
# ডিফল্টে ২৪-এর বেশি নয়, রিড-অনলি ছাড়া লেখার টুল নেই
curl -s -X POST localhost:5050/mcp -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' \
 | node -e 'let s="";process.stdin.on("data",d=>s+=d).on("end",()=>{const t=JSON.parse(s).result.tools;
   console.log(t.length<=24 ? "budget ok" : "BUDGET FAIL");
   console.log(t.some(x=>x.name==="write_file") ? "LEAK FAIL" : "read-only ok")})'
# স্পষ্ট অনুমতি দিলে ঠিক সেটাই
curl -s -X POST localhost:5050/mcp -H 'content-type: application/json' \
 -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{"mcp":{"tools":["write_file"]}}}' \
 | grep -c write_file
```
**প্রত্যাশিত:** `budget ok`, `read-only ok`, শেষটা `>0`।

## ৫. ধাপ ২ — মেটা-কিওয়ার্ড: ইনটেন্ট → টুল শর্টলিস্ট

**আছে:** `lib/tool-budget.js`-এ `strategy: "intent"` এবং নাম-স্কোর। `api.js`-এ ইনটেন্ট প্যাটার্ন ইঞ্জিন দুটো (`AUDIT §৩.৪`)।

**গ্যাপ:** ক্লায়েন্ট পাঠায় ইংরেজি/বাংলা মিশ্র ইনপুট, সার্ভার স্কোর করে — কিন্তু ব্যবহারকারী নিজে টুল বাছতে পারে না, আর "কোন টুলগুলো লাগবে" সেটা সেশনজুড়ে স্থির থাকে না।

**করণীয়:** ইনপুটের প্রথম লাইনে একটি মেটা-কিওয়ার্ড:
```
@tools note_get,note_list
@tools none
```
- `@tools` লাইন প্রম্পট থেকে **কাটা হবে** (মডেল দেখবে না), শুধু পলিসি হিসেবে ব্যবহৃত হবে।

### ১১.১ তিনটি ডিরেক্টরি, তিনটি মালিক (এই নিয়ম এখন কোথাও লেখা নেই)

এই সারণিটা `docs/`-এ থাকলেই "পাথ সমস্যা" আর অনুমানের বিষয় থাকে না।

### ১১.২ অ্যাডমিন অরিজিন — ঠিক করা হয়েছে

`isOriginAllowed()` এখন শুধু একটি বাড়তি কেস মানে: `Origin` আর `Host` — দুটোই **loopback literal** (`127.0.0.1`, `localhost`, `::1`) এবং পোর্টসহ হুবহু এক। ফলে `http://127.0.0.1:5050` থেকে আসা অ্যাডমিন পেজের `write_file` আর ব্লক হবে না।

শুধু “হোস্ট মিললে ছাড়” — এটা করা হয়নি, কারণ DNS-rebinding পেজ ঠিক সেই তুলনাটাই ফাঁকি দেয় (Host ও Origin দুটোই attacker-domain হয়)। তাই নিয়ম সংকীর্ণ: দুই দিকই loopback literal হতে হবে, আর loopback literal কখনো rebind হয় না।

**যাচাই (৭টি কেস, প্যাচের পরে চালানো):**

| কেস | ফল |
|---|---|
| অ্যাডমিন UI (`http://127.0.0.1:5050`) | allow |
| পাবলিক https অরিজিন | allow |
| DNS rebinding (`Origin` ও `Host` = attacker domain) | **deny** |
| loopback অরিজিন + অন্য হোস্ট | **deny** |
| একই হোস্ট, অন্য পোর্ট | **deny** |
| অরিজিন হেডার নেই (নেটিভ ক্লায়েন্ট) | allow |

লাইভ যাচাই: পুনরায় চালুর পর লগে নতুন `MCP_GATE_DENIED ... "origin":"http://127.0.0.1:5050"` থাকবে না, কিন্তু `origin` অন্য হোস্টের হলে আগের মতোই ৪০১/৪০৩ থাকবে।

### ১১.৩ হেডার রিজেক্ট — এখন কারণ লগে

`MCP_HEADER_REJECTED`-এ `detail` যোগ হয়েছে (`field=value`)। যাচাই: পরের রিজেক্টে লগে ভ্যালু দেখা যাবে, তারপর ঠিক করা যাবে কোন ক্লায়েন্ট ভুল পাঠাচ্ছে।

### ১১.৪ TLS/প্রক্সি সীমানা

Caddy (`/etc/caddy/Caddyfile`, `reverse_proxy 127.0.0.1:5050`) + Cloudflare tunnel। এর অর্থ:
- সার্ভারের কাছে **প্রতিটি ইন্টারনেট অনুরোধ 127.0.0.1 থেকে আসে** — তাই "loopback = বিশ্বস্ত" ধারণা এখানে ভুল।
- প্রক্সি হেডার (`cf-connecting-ip`, `x-forwarded-for`) থাকা মানে অনুরোধ বাইরে থেকে এসেছে। এই পার্থক্যটাই অথেন্টিকেশন গেটের ভিত্তি হতে হবে, `remoteAddress` নয়।
- ৪০০/৪৩৮০ সীমান্ত: Caddy ৪৪৩-এ শোনে, Node ৫০৫০-এ। বাইরের কেউ ৫০৫০-এ সরাসরি পৌঁছাতে পারে কি না — ফায়ারওয়ালে ৫০৫০ বন্ধ থাকা উচিত; যাচাই `ss -ltnp | grep 5050` এবং বাইরে থেকে `curl -m 3 http://<public-ip>:5050/health` (সংযোগ ব্যর্থ হওয়া = ঠিক)।

## ১২. ধাপ ৯ — মিনিমাম অথেন্টিকেশন (নিজের প্রজেক্টের জন্য, বিক্রির জন্য নয়)

**আছে:** `users` (`id,name,api_key,enabled,token_limit,valid_days,token_used,expires_at`), `sessions`, `/api/auth/*`, `ADMIN_TOKEN`, `authFromRequest()`।

**গ্যাপ:** `clients`/`projects` নেই; তাই "কোন প্রজেক্টের মালিক কে" বলা যায় না, আর প্রতি-প্রজেক্ট কোটা বসানো যায় না।

**করণীয়:**
```sql
CREATE TABLE IF NOT EXISTS projects (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  owner_user_id TEXT NOT NULL REFERENCES users(id),
  root_dir TEXT NOT NULL,
  project_id TEXT NOT NULL,          -- §৮-এর hash
  enabled INTEGER NOT NULL DEFAULT 1,
  created_at INTEGER NOT NULL
);
```
- `authFromRequest()` ইতিমধ্যে `users.api_key`-এর sha256 দেখে — নতুন টেবিল শুধু স্কোপ যোগ করবে: কী → ইউজার → প্রজেক্ট।
- কোটা (`token_limit`, `valid_days`) ইতিমধ্যে `checkUserLimits()`-এ আছে; প্রজেক্ট-স্কোপে একই কল।
- সীমা: এটি নিজের cPanel ক্লায়েন্টের জন্য, API/এডিটর বিক্রির জন্য নয় — ডকুমেন্টেই সীমা লিখিত থাকবে।

**যাচাই:** এক ইউজারের কী দিয়ে অন্য প্রজেক্টের `/api/set-working-dir` → 403; নিজের প্রজেক্টে 200।

## ১৩. ধাপ ১০ — ফ্রন্টএন্ড ও স্বাধীনতা

**নীতি:** প্রতিটি অংশ স্বাধীন। ZombieCoder বন্ধ থাকলেও Softaculous ফ্রন্টএন্ড চলবে (সরাসরি প্রোভাইডার + নোট সার্ভার)। নোট সার্ভার বন্ধ থাকলেও চ্যাট চলবে (localStorage + সরাসরি API)।

**করণীয়:**
1. UI শুধু OpenAI-সামঞ্জস্য `/v1/chat/completions` ও `/v1/models` ডাকবে — অন্য কোনো কাস্টম ফরম্যাট নয়। ফলে v0, OpenCode, Softaculous — সবাই একই সার্ভারে যুক্ত হতে পারবে।
2. `mcp` প্যারামিটার UI থেকে পাঠানো হবে (চ্যাট সেটিংসে "টুল পলিসি"), ব্রাউজারে কী নয় — সার্ভার-সাইড প্রক্সি।
3. স্ট্রিমিং CDN/প্রক্সি ব্যর্থ হলে Pusher ফলব্যাক (যা ইতিমধ্যে কনফিগে আছে)।
4. cPanel-এ বড় পেলোড নয়: PDF/ইমেজ আপলোড → সার্ভারে এক্সট্রাক্ট → টেক্সট ফেরত।

**যাচাই:** ZombieCoder বন্ধ করে (`systemctl stop`/`kill`) UI-তে চ্যাট ও নোট — দুটোই কাজ করবে; নোট সার্ভার বন্ধ করে চ্যাট — কাজ করবে।

**আছে:** `tools/tools-manifest.js` (কোর/শিপড/প্লাগেবল আলাদা করে), `AUDIT` (সংখ্যাগুলো ব্যাখ্যা করে)।

**গ্যাপ:** একই সময়ে ৩৬, ১০১, ১৫৫ — তিন জায়গায় তিন সংখ্যা।

## ১৫. প্রতিটি ধাপের Definition of Done

একটি ধাপ "সম্পন্ন" তখনই, যখন নিচের চারটি একসাথে সত্য:

1. ডকুমেন্টে লেখা **যাচাই কমান্ড** চালানো হয়েছে এবং **প্রত্যাশিত আউটপুট** মিলেছে।
2. একই কাজের অন্য implementation-টি মুছে গেছে (অথবা কেন থাকল, এক লাইনে লেখা আছে)।
3. লগে নতুন `WARN`/`ERROR` তৈরি হয়নি (আগেরটার সাথে তুলনা করে)।
4. `node --check` এবং সংশ্লিষ্ট টেস্ট পাস।

এর একটিও না মিললে ধাপটি "সম্পন্ন" নয় — সেটি ডকুমেন্টে ব্যর্থ হিসেবে লিখতে হবে।

## ১৬. যা করা যাবে না

- `index.php` (Softaculous ফ্রন্টএন্ড) সম্পাদনা — এটি অপরিবর্তিত থাকবে।

- ব্রাউজারে API key রাখা।
- `.env` বা `paten.md`-এর টোকেন কোথাও কপি করা।
- নতুন ফ্রেমওয়ার্ক/প্যাকেজ যোগ করা — যা আছে (`node:sqlite`, `node:http`, `normalizer`, `lib/tool-budget.js`) তাই দিয়ে হবে।
